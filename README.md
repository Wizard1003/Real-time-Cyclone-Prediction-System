# Real-time-Cyclone-Prediction-System
The Real-Time Cyclone Prediction System is a Python-based web application that predicts and visualizes cyclone risk levels using real-time weather data.
Built with Streamlit, Plotly, and the Tomorrow.io API, this system fetches live weather parameters—like wind speed, humidity, temperature, and pressure to calculate a Cyclone Risk Score (0-100) and classify it into Minimal, Low, Moderate, High, or Extreme risk levels.
